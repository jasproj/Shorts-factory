Prices are NEVER taken from this sheet — they come live from the FareHarbor API at render time.

## Corrections to older material
- **S60 Shorts pack, script #2 ("tours run anyway on a full moon")** — half wrong. TRUE for Fajardo (F09), FALSE for Vieques (F08). Script 02 below replaces it.
- **S60 "45 minutes from San Juan"** — use "about an hour" (F05).

## Conflicts / do-not-use
- Some third-party listings advertise "swim in Mosquito Bay" — conflicts with F03. Do not claim it either way beyond F03.
- Dinoflagellate counts per gallon/liter vary wildly by source — do not use numbers.
